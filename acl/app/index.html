KeyValueStore ACL Builder How to use it

A user's rules

Paste the rules of a user: the arguments of ACL SETUSER, a line of ACL LIST, the user lines of redis.conf or a whole ACL file. The builder applies them the way the server you pick does, and says what the user can do.

Nothing you paste leaves your browser.

Can it run this?

One command per line, as you'd type it in redis-cli or valkey-cli; MONITOR output works too. Each is checked against the user above the way ACL DRYRUN checks it, with the error the command itself would get.

Such as GET app:42

Draft a user from what a client does

Run MONITOR in redis-cli or valkey-cli while the app works, then paste what it printed. The builder drafts a user that may run those commands and no others, with key and channel patterns made from the names it saw, and checks every line against it. MONITOR slows a busy server down, so keep it short.

redis-cli MONITOR > monitor.txt
Runs in your browser and sends nothing anywhere. The page's security policy stops it from fetching or loading anything from another site. Source code, Apache License 2.0.
