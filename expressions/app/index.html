KeyValueStore Expression Tester How to use it

The request

Write the expressions your code sends, or paste the whole request. The tester checks them the way DynamoDB does, in the same order, and answers with the same error message DynamoDB would.

Paste a whole request instead

The table and its items

The key schema lets the tester check the rules DynamoDB applies to keys. The items are made up or copied from your table, and the request runs on them.

What DynamoDB does

Runs in your browser and sends nothing anywhere. The page's security policy stops it from fetching or loading anything from another site. Source code, Apache License 2.0.
