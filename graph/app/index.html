KeyValueStore Graph Key Builder How to use it

Turn links into keys

One link a line: from type to, or from,type,to when names have spaces. You get every key the graph takes in an ordered key-value store, in the order the store keeps them.

Follow the links

Each hop scans one prefix per node, the way a graph layer on a key-value store does. The count of scans and keys read is what the walk costs.
