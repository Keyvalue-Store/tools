KeyValueStore Mass Insert Builder How to use it

Build a file for --pipe

Paste CSV, JSON or plain commands. You get a file in the Redis protocol that redis-cli --pipe or valkey-cli --pipe loads at full speed, without a round trip per command.

How each record is stored

Write ${name} to take a field. A hash tag keeps related keys together in a cluster: cart:{${user}}:items.

Read protocol bytes

Paste protocol data to see it as commands and replies: a capture, a log line with \r\n written out, or a hex dump. Or load a file this page built.
