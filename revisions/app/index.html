KeyValueStore Revision Viewer How to use it

Open a snapshot

Load a snapshot made with etcdctl snapshot save backup.db, or a member's own database file, member/snap/db in its data folder, copied while etcd is stopped. Snapshots from etcd 3.5 and 3.6 work, and Kubernetes objects show as kubectl get -o yaml shows them.

Browse the keys

Find a key, then pick it to see every revision the file keeps and what changed in each.
