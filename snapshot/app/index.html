KeyValueStore Snapshot Viewer How to use it

Open a snapshot

Load an RDB file: the dump.rdb in a server's data folder, or one made with redis-cli --rdb dump.rdb or valkey-cli --rdb dump.rdb, which asks a running server for a copy. Snapshots from Redis 2.6 to 8.10 and Valkey 7.2 to 9.1 work.

Drop a snapshot here, or

Browse the keys

Filter by part of a key name or by type, then pick a key to see its value.

Read a DUMP payload

The DUMP command returns one key's value in the snapshot format. Paste what redis-cli or valkey-cli printed, quotes and \x escapes included, or the payload as hex.
