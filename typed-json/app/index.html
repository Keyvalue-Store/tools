KeyValueStore Typed JSON Converter How to use it

Convert DynamoDB JSON

Paste typed JSON, such as the output of aws dynamodb scan, to get plain JSON. Paste plain JSON to get typed JSON you can send to DynamoDB. The direction is picked for you.

When the result is typed JSON

Runs in your browser. This page tells the browser to block any network request it might make, so nothing you paste or load leaves it. Source code, Apache License 2.0.
